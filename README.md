# 🌤️ Weather Cast - 프리미엄 글로벌 날씨 대시보드

PC와 모바일 모든 환경에 최적화된 **반응형 실시간 날씨 포털 서비스**입니다.  
별도의 회원가입이나 **API Key 발급 없이 100% 무료 공개 날씨 API(Open-Meteo)**를 기반으로 동작합니다.

---

## 🌟 주요 기능 및 특징

1. **PC & 모바일 반응형 대시보드 레이아웃**:
   - **PC 화면 (와이드 모니터)**: 2개 열(좌측: 현재 날씨 + 24시간 예보, 우측: 6대 기상 지표 + 7일 주간 예보)로 넓은 화면을 효율적으로 활용
   - **태블릿 / 모바일**: 가독성과 터치 조작성을 고려한 세로 스택 및 부드러운 가로 스와이프
2. **실시간 현재 날씨 & 상태 이모지**:
   - 현재 기온 및 체감 온도, 오늘 최고/최저 기온
   - 생생한 대형 이모지(☀️, ⛅, 🌧️, ❄️, ⛈️ 등)와 플로팅 아이콘
   - 직관적인 상태 뱃지 (예: `☀️ 맑음`, `🌧️ 비`, `❄️ 눈`)
3. **24시간 시간별 예보 (24h Hourly Forecast)**:
   - '지금'부터 향후 24시간 동안의 시간별 날씨 상태, 이모지, 기온, 강수 확률(%)을 가로 스크롤로 확인
4. **상세 기상 지표 (Weather Metrics 6종)**:
   - 습도(%), 바람(km/h), 구름양(%), 강수량(mm), 자외선 지수(UV), 일출/일몰 시간
   - 각 지표별 유용한 상태 해설(적정 습도, 산들바람, 쾌청 등) 제공
5. **주간 7일 예보 & 기온 게이지 바**:
   - 요일별 날씨 상태, 강수 확률
   - 애플 날씨 스타일의 최저~최고 기온 시각화 게이지 바 탑재
6. **위치 검색 & 스마트 Geolocation**:
   - 한국어 및 영문 도시/지역 검색 지원 (서울, 강릉, 해운대, 도쿄, 뉴욕, 파리 등)
   - 원클릭 주요 도시 퀵 칩 필터
   - 브라우저 GPS 기반 '내 위치' 자동 감지
7. **날씨 상태별 동적 무드 배경**:
   - 맑음, 흐림, 비, 눈, 밤 등의 날씨 분위기에 맞춰 자연스럽게 변화하는 글래스모피즘 테마

---

## 🖥️ 실행 방법

별도의 서버 설치나 빌드 과정 없이, 웹 브라우저에서 바로 열 수 있습니다.

- 파일 탐색기에서 **`index.html`** 파일을 더블 클릭하여 크롬/엣지/웨일 등의 브라우저로 엽니다.
